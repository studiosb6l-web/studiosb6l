Experimental Android home-screen widget for issue #68. ViewFlipper animation is launcher-dependent; no timers, alarms, network or background services. Build requires JDK 17, Gradle 8.9, Android SDK 35. Copy assets/brand/studiosb6l-icon-192.png into app/src/main/assets/official.png before building. Run gradle :app:assembleDebug. Install debug APK, add widget via launcher widget picker. Test animation, tap, screen-off and battery. This is not a replacement for the PWA launcher icon. Four-frame proof of concept, not final smooth orbit. No release until physical validation.
