# STUDIOSB6L International Opportunities — implementation plan
Status: source-only foundation on draft branch; **not live**.
1. Smart search: public approved professional profiles, disciplines, location, availability and skills, with explainable filters.
2. Private messaging: authenticated participants, anti-spam, reporting, moderation, retention and GDPR rights.
3. Video calls/auditions: provider selection, consent, accessibility, no default recording, abuse reporting.
4. Conversation translations: opt-in translation, clear machine-translation labels, privacy safeguards.
5. Project listings/auditions: approved employers, deadlines, moderation, application tracking and notifications.
6. Verified reputation: review only after confirmed in-platform transaction; appeals and anti-manipulation.
7. Matching engine: explainable suggestions, user opt-out, no protected-trait scoring or automated hiring decisions.
8. Integrate payments/contract workflow only after existing issuance and fraud gates pass.
Release gates: access controls, identity checks, moderation, rate limits, load tests, translations PT/EN/ES/FR/DE/JA/ZH/AR, mobile accessibility, staging QA, legal review.
